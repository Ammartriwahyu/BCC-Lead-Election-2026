# Deviations from Figma

Everything that differs from, or is missing in, the Figma section **Pilketum – v2** (`8:3924`), with the reason. Updated every phase.

## Phase 1–2 (setup, foundation)

| #   | Area       | What                                                                                                                                                  | Why                                                                                                                                                                                                                           |
| --- | ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Mock / dev | Scenario switcher (floating "Mock" button) and `/dev/gallery`                                                                                         | Dev/demo tools to test every flow without a backend. Compiled out of production builds (`pnpm check:bundle`)                                                                                                                  |
| 2   | Sign in    | Unknown emails are treated as `NOT_A_VOTER` (email field error)                                                                                       | Matches the V0d copy "This email isn't on the voter register." Open question for the backend (account enumeration)                                                                                                            |
| 3   | Button     | Primary uses `semantic/action/primary` (#226A9A) instead of the DS default `#3598DB` + 20% black                                                      | Spec §8: AA contrast. Hover `primary/700`, pressed `primary/800` as in the DS variants                                                                                                                                        |
| 4   | Button     | Hover/pressed states for `dark` (Selected, committee Sign in), `on-dark` (Sign out, Select this candidate) and `outline-on-dark` (Back to candidates) | Figma only defines hover/pressed for the primary and outline buttons. Used neighbouring tokens: dark → `primary/700` / `primary/900`; on-dark → `primary/50` / `primary/100`; outline-on-dark → `primary/700` / `primary/900` |
| 5   | Button     | Outline border is 1px (Pilketum instances), not 1.5px (DS variant)                                                                                    | Pilketum v2 screens use 1px everywhere                                                                                                                                                                                        |
| 6   | Button     | Loading state: 20px spinner inside the button                                                                                                         | Needed for "Confirm" buttons during requests (spec §4.4). Uses the Figma Spinner shapes and tokens                                                                                                                            |
| 7   | Form       | Error field uses `semantic/text/danger` (#B83D00) for label, border and message, and `neutral/100` (#EAEAEA) background                               | V0d uses off-token `#CC0000` and `#F1F1F1` from the old BCC form. Mapped to the nearest tokens                                                                                                                                |
| 8   | Form       | Email and password boxes both use a 1px `border/default`                                                                                              | Figma mixes 1px (email) and 1.5px (password)                                                                                                                                                                                  |
| 9   | Form       | Focus: 2px `action/primary` ring with 2px offset on every control (white ring on navy surfaces)                                                       | Spec §8; Figma has no focus state                                                                                                                                                                                             |
| 10  | Form       | Password toggle icon uses `text/secondary` (not `neutral/200`) and an "eye-off" icon when the password is shown                                       | `neutral/200` on white is 1.4:1, below the 3:1 needed for a control. Eye-off icon does not exist in Figma                                                                                                                     |
| 11  | Icons      | `CloseIcon` for the admin drawer                                                                                                                      | Drawer is new (see #13)                                                                                                                                                                                                       |
| 12  | Brand      | Logo asset trimmed and scaled to 404×166 (4× navbar size)                                                                                             | The MCP-exported PNG differs from the Figma crop. Result compared visually with the Figma render of `36:2905` (same proportions)                                                                                              |
| 13  | Admin      | Sidebar becomes a top bar + slide-in drawer below 1024px                                                                                              | Spec §6: admin must be usable from 1024px; below that the sidebar would cover content                                                                                                                                         |
| 14  | Layout     | Decorations only from 1024px, always behind content; hidden on mobile                                                                                 | MV frames have no decorations; at 768–1023 they would sit under the status card                                                                                                                                               |
| 15  | Layout     | Horizontal page padding 16 → 40 (≥768) → 64 (≥1280) → 100 (≥1512)                                                                                     | Figma only has 390 and 1512 frames                                                                                                                                                                                            |
| 16  | Pages      | 404 and error pages in the V6 status-card style, Brace "Woah", copy in `content/copy.ts` (NEW)                                                        | Not in Figma; spec asks for them in BCC style                                                                                                                                                                                 |
| 17  | UI         | Toast (white card, 4px left accent: brand for info, danger for errors, Shadow dropdown)                                                               | Needed for admin `STATE_CONFLICT` (spec §4.4). Not in Figma                                                                                                                                                                   |
| 18  | UI         | Skeleton (bg/subtle, pulse)                                                                                                                           | Loading states are not in Figma                                                                                                                                                                                               |
| 19  | Assets     | Committee photo (A0) recompressed: 4096×2731 JPEG → 1600px WebP (8.3 MB → 120 KB)                                                                     | Performance budget. Panel is 766px wide, so 1600px covers 2× screens                                                                                                                                                          |
