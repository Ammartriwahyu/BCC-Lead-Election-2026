## Answered by the doc

| Topic             | Answer                                                                                                                                                 | Frontend change                                                         |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------- |
| Auth              | Bearer tokens, voter 2 h / committee 12 h, no cookies; voter token on admin endpoints → `403 FORBIDDEN`                                                | BFF in the Next server keeps tokens in httpOnly cookies (`src/lib/bff`) |
| Sign-in           | UB SSO, NIM or UB email; 2FA via `/auth/otp`; `NOT_REGISTERED`, `RATE_LIMITED` (+ `Retry-After`), `SSO_UNAVAILABLE`, `SSO_BUSY`; works in every status | Field "NIM or UB email", OTP step, new banners                          |
| Vote              | `POST /votes { candidate_id }` → `201 { voted: true }`; no idempotency key; `VOTING_NOT_OPEN` for not-open and closed; one anonymous ballot            | Retry checks `has_voted` first; `VOTING_NOT_OPEN` refetches the status  |
| Committee actions | `INVALID_STATE`; display screens only while `closed` (`RESULTS_LOCKED`); reopen switches to `voting_open` (guards added 18 Nov, see above)             | `INVALID_STATE` → conflict toast; result screens disabled unless closed |
| Results           | `409 RESULTS_LOCKED` unless closed; `leaders`, `top_tied`, `integrity_ok`; Excel export                                                                | Integrity warning, Export button                                        |
| Candidates        | CRUD + photo, only before voting first opens (`CANDIDATES_LOCKED`), ballot numbers 1–3                                                                 | A6–A8 built from the new Figma frames                                   |
| Display           | SSE `display` event = `GET /display`, first event on connect; no `version`                                                                             | Feed drops a poll answer older than the last stream event               |
| Format            | snake_case, lowercase enums, ISO-8601 UTC, numeric ids, `{ error: { code, message, fields? } }`                                                        | Schemas and mappers in `lib/api`                                        |
